# v1.0.0 Release Notes

首个 Android 离线版候选发布。

## 功能

- 22 章、3,670 个词条与全书搜索；
- 单词和例句音频；
- 337 页原页对照与词条跳转；
- 手机、平板、横屏和系统安全区域适配；
- 记忆上次章节、页码和阅读模式；
- 不申请网络权限。

## 安装包

- 文件：`IELTS-Vocabulary-Offline-Android-1.0.0.apk`
- 最低系统：Android 7.0（API 24）
- 当前候选包：Android 调试签名
- 大小：709,486,144 bytes（约 676.62 MiB）

SHA-256 见同目录 `SHA256SUMS.txt`。公开发布前请按 `docs/RELEASING.md` 完成真机、签名和版权确认。
